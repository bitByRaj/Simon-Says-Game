# 🎮 Simon Says Game

A responsive Simon Says memory game built using HTML, CSS, and JavaScript.

## 🚀 Features

- 🎯 Random color sequence generation
- 🧠 Increasing difficulty with each level
- ✨ Game and user button animations
- 🏆 Highest level tracking
- 🔄 Game reset functionality
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎮 How to Play

1. Press any key to start the game.
2. Watch the color that flashes.
3. Click the buttons in the same sequence.
4. Each successful round increases the level.
5. If you click the wrong button, the game ends.
6. Try to beat your highest level!
